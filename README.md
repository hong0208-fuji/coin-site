# coin — 바이낸스 AI 자동매매 웹서비스

로그인 후 GO/STOP 버튼만으로 AI가 바이낸스에서 자동매매를 수행/중단할 수 있는 개인용 웹 서비스.

## 진행 단계

현재 **1단계**: 전체 아키텍처 기획 문서 + 로그인/대시보드 디자인 목업 작성 단계. 실제 동작하는 서버/거래소 연동/AI 판단 로직은 아직 구현되지 않았다.

## 문서 및 목업 위치

- `docs/ARCHITECTURE.md` — 전체 시스템 설계, AI 판단 방식, 리스크 관리, 로드맵
- `mockup/` — 로그인/대시보드 정적 디자인 목업 (`login.html`, `dashboard.html`을 브라우저로 직접 열어서 확인)

## 로드맵

1. 기획 문서 + 목업 (현재)
2. Express 서버 골격 + 실제 로그인 + GO/STOP 상태 API
3. 바이낸스 모의투자(paper trading) 연동
4. AI 판단 로직 구현 + 백테스트
5. 리스크 관리 강화 후 소액 실거래 전환
