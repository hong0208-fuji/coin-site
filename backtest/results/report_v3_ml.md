# 백테스트 결과 v3 - ML(그래디언트 부스팅) 신호 생성 (3년치 BTCUSDT 1시간봉)

규칙 기반 크로스오버 대신, 다변수 피처(수익률/RSI/MACD/볼린저/변동성/거래량/펀딩비율/매크로 플래그/시간대/SNS감정점수)로
향후 N봉 수익률을 예측하는 HistGradientBoostingRegressor를 사용. 3요인+감정 필터(v2)는 진입 게이트로 계속 사용.
**이 버전은 포지션 사이징을 전액배팅 -> 리스크기반(손절 시 자본의 1%만 손실)으로 고친 뒤 재실행한 결과다.**

- model_train: ~2025-04-18 이전 (모델 학습 전용, 파라미터 탐색에 사용 안 함)
- model_val: 2025-04-18 ~ 2025-08-16 (진입임계값/손절익절/보유기간 자체탐색)
- test: 2025-08-16 이후 (한 번만 검증한 진짜 out-of-sample)
- 탐색한 매매 파라미터 조합 수: 144 (horizon 2종 x 그리드)

**해석**: 포지션 사이징을 고치니 손실의 "심각도"는 확실히 줄었다(test -27.88% → -10.61%, 최악의 경우도 -94%대에서 완화됨). 하지만 **144개 조합 중 양수가 하나도 없다는 사실 자체는 바뀌지 않았다** — 즉 사이징 문제와 신호 품질 문제는 서로 다른 문제였고, 둘 다 존재했다. 사이징을 고쳐서 "덜 위험하게 잃는" 상태는 됐지만, 아직 "이기는" 전략은 아니다. SNS 감정(공포탐욕지수) 피처를 추가한 것도 이번 결과에 포함되어 있지만, 이것만으로 흑자 전환에는 이르지 못했다.
