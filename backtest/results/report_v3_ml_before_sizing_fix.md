# 백테스트 결과 v3 - ML(그래디언트 부스팅) 신호 생성 (3년치 BTCUSDT 1시간봉)

규칙 기반 크로스오버 대신, 다변수 피처(수익률/RSI/MACD/볼린저/변동성/거래량/펀딩비율/매크로 플래그/시간대)로
향후 N봉 수익률을 예측하는 HistGradientBoostingRegressor를 사용. 3요인 필터(v2)는 진입 게이트로 계속 사용.

- model_train: ~2025-04-18 이전 (모델 학습 전용, 파라미터 탐색에 사용 안 함)
- model_val: 2025-04-18 ~ 2025-08-16 (진입임계값/손절익절/보유기간 자체탐색)
- test: 2025-08-16 이후 (한 번만 검증한 진짜 out-of-sample)
- 탐색한 매매 파라미터 조합 수: 144 (horizon 2종 x 그리드)

## v1/v2 대비 비교 및 중요한 추가 발견

| 버전 | 방식 | out-of-sample 수익률 |
|---|---|---|
| v1 | 롱온리, 규칙기반(MA+RSI) | -26.21% |
| v2 | 롱+숏, 규칙기반 + 3요인 필터 | -23.63% |
| v3 | 롱+숏, ML(그래디언트 부스팅) + 3요인 필터 | **-27.88%** |

**ML로 바꾼다고 좋아지지 않았다.** model_val(파라미터 선택 구간)에서 테스트한 144개 조합 중 **단 하나도 플러스가 없었다**(평균 -65.7%, 최댓값이 -9.23%). 그중 가장 나은 걸 골랐는데도 test에서는 v1/v2보다 더 나쁜 -27.88%가 나왔다.

**overfitting과는 다른, 더 심각한 구조적 문제를 발견했다**: 최악의 조합(진입임계값을 낮게 잡은 경우)은 4개월 동안 **1,382번 거래**가 발생했고 결과는 **-94.61%**였다. 이건 모델이 나빠서라기보다, 지금까지 v1~v3 백테스트 전부가 **매 거래마다 자본 전액(all-in)을 거는 방식**이었기 때문이다. 승률이 50%를 살짝 밑도는 애매한 전략이라도, 전액배팅을 수백~수천 번 반복하면 손실이 곱셈으로 누적되어 파산에 가까워진다. 반대로 거래 비중을 자본의 10~20%로만 제한했다면 같은 전략이라도 손실 폭이 훨씬 작았을 것이다.

**결론**: 이번 실험에서 얻은 가장 중요한 교훈은 "어떤 신호 생성 방식(규칙기반 vs ML)이 더 나은가"가 아니라, **포지션 사이징(전액배팅) 자체가 지금까지의 모든 백테스트에 숨어있던 위험 요소였다**는 것이다. 다음 개선은 신호 로직보다 포지션 사이징(예: 고정 비율 또는 켈리 기준 기반)을 먼저 고치는 게 더 근본적일 가능성이 높다.
